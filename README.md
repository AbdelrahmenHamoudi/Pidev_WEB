# Pidev_WEBRE7LA (رحلة) is a modern travel & leisure ecosystem designed to simplify how users discover, book, and enjoy travel experiences across Tunisia.
The platform combines accommodation booking, activities, transportation, and promotional offers into one connected and user-friendly experience.

Built as part of a PIDEV academic project, RE7LA integrates:

 A Symfony Web Application
 A JavaFX Desktop Application
 A Shared MySQL Database with Real-Time Synchronization
